# Contributing

We welcome contributions.

## Filing an issue

- Search existing issues first.
- Ideally include a minimal reproducible example (consider adding `pixi list`).

## Pull requests

- Scope each PR to one change. Please don't add new modules, dependencies, or unrelated refactors without discussing first (open an issue).
- Describe what changed and why.
- Link related issues.

## AI-assisted contributions

We welcome AI-assisted code under these conditions:

1. **Human-reviewed**: you understand and can defend the changes.
2. **Well-scoped**: matches the PR's stated purpose. No incidental changes, new modules, or new
   dependencies unless you discussed them first.
3. **Precise**: the PR description states what changed and why. Show a before/after example
   where it clarifies the change.
4. **No AI slop**: AI tends to add unnecessarily long comments in the code, PR descriptions,
   and reimplement code. Changes should be intentional, short, and clear.
