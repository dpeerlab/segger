# Segger v0.2.0 Release Notes

Release date: 2026-02-12

## 1. High-level

- Added checkpoint-only inference via `segger predict` with strict metadata validation.
- Added training observability and control improvements: early stopping, best-checkpoint prediction, and CLI loss plotting.
- Expanded export support to multiple targets (`xenium_explorer`, `merged`, `spatialdata`, `anndata`) behind one command.
- Improved robustness in boundary generation, optional dependency checks, and model positional embedding edge cases.

## 2. Low-level

- CLI:
  - Added `segger predict -c <checkpoint>` to run inference without retraining.
  - Added `segger plot` (`--quick` terminal mode and PNG output).
  - Added `--early-stopping-patience` and `--early-stopping-min-delta` to `segger segment`.
  - `segment` now saves/uses best checkpoints for prediction when available.
  - `export` now supports input autodetection and richer boundary controls.
- Data and model:
  - Checkpoints now persist `segger_vocab` and `segger_me_gene_pairs`.
  - `ISTDataModule` can consume fixed `vocab` and precomputed `me_gene_pairs`.
  - AnnData setup supports fixed feature vocab ordering and explicit empty-data errors.
  - Dynamic prediction batching now has deterministic length behavior.
- Export:
  - Xenium export supports boundary-mode selection and safer fallbacks.
  - Parallel Xenium export retries with thread workers if process workers fail.
  - SpatialData export now consistently carries a `cell_id` column for points/shapes.
  - AnnData export improved type-safe filtering for unassigned IDs.
- Stability, tests, docs:
  - Optional dependency checks now use lightweight module discovery.
  - Positional embedding handles empty/constant-coordinate inputs without NaNs.
  - Added tests for checkpoint metadata parsing and positional embedding edge cases.
  - Added plotting guide notebook and updated installation/usage docs.
